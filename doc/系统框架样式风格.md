一、系统视觉风格方案（基于广州地铁品牌基因）
1.1 品牌色彩体系
广州地铁品牌色以红色为主色调，象征热情、活力与安全；搭配深灰/铁灰色体现稳重、可靠的地铁行业属性。

用途	颜色值	色值示例	说明
品牌主色	#DA251D / #E50012	红色	广州地铁标志红，用于导航栏背景、主按钮、Logo强调色
品牌主色-深	#B71C1C	深红	导航栏选中态、按钮Hover态
辅助色-铁轨灰	#4A4A4A	深灰	顶部导航文字、侧边栏文字、重要标题
辅助色-浅灰	#8C8C8C	中灰	次要文字、提示信息
辅助色-背景灰	#F0F2F5	浅灰	页面背景色
辅助色-卡片白	#FFFFFF	纯白	内容卡片背景
边框分割	#E4E7ED	浅灰边框	分割线、边框
功能色-成功	#00A854	绿色	任务成功、连接正常、通过
功能色-警告	#ED7B2F	橙色	待处理、告警
功能色-危险	#E34D59	红色	故障、异常、失败
功能色-信息	#2B6CB0	科技蓝	信息提示、数据高亮、图表配色
1.2 品牌Logo与系统标识
广州地铁官方标识为核心视觉元素，系统名称与标识的组合规范如下：

│  ◆ 广州地铁标识 + "广州地铁"文字 (红色)                        │
│  新线建设数据治理系统 (中黑/深灰色)                             │
│  Guangzhou Metro New Line Construction Data Governance System │
└──────────────────────────────────────────────────────────────┘
标识组合规范：

标识左侧为广州地铁官方Logo（红色菱形+轨道图形+Guangzhou Metro文字）

Logo右侧紧邻系统中文全称"广州地铁新线建设数据治理系统"

中文下方为英文全称（较小字号，灰色）

1.3 品牌色应用规范
应用场景	颜色方案	说明
顶部导航栏背景	红色渐变 #DA251D → #B71C1C	从左至右渐变，稳重有力
导航栏文字	#FFFFFF（白色）	保持高对比度，清晰可读
导航栏Logo区域	左侧"广州地铁标识+系统名称"白色	品牌统一输出
侧边栏背景	#FFFFFF（白色）	简洁清爽
侧边栏选中菜单	红底白字（#DA251D背景+白色文字）	与导航栏呼应
侧边栏菜单图标	默认灰色#8C8C8C，选中红色#DA251D	品牌色点缀
一级按钮	红色背景 #DA251D + 白色文字	主操作按钮
二级按钮	白色背景 + 红色边框 #DA251D + 红色文字	次要操作
数据卡片标题装饰	左侧红色竖条装饰 #DA251D	卡片标题区点缀
状态标签	红色标签（待处理）/绿色（正常）/橙色（告警）	符合功能色规范
图表配色	红色 #DA251D + 科技蓝 #2B6CB0 + 橙色 + 绿色	ECharts图表系列色
版权信息	底部深灰背景 #4A4A4A + 白色文字	稳重收尾
1.4 字体规范
中文字体：思源黑体（Noto Sans SC）/ 微软雅黑 —— 与广州地铁官方视觉一致

英文字体：Segoe UI / Arial

标题字号：24px（H1）/ 20px（H2）/ 16px（H3）

正文字号：14px

辅助字号：12px

导航栏Logo字体：18px（中文）/ 12px（英文）
