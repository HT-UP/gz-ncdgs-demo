二、页面详细内容
页面1：智能总览
路径： /intelligence/overview
图标： Monitor
核心功能：

智能体运行状态看板（4个智能体卡片：元数据/质量/资源/找数）

核心指标展示：元数据自动抽取准确率、业务元数据补全准确率、资产分类分级准确率、质量规则自动生成准确率、质量异常根因定位准确率、自动化报告生成合规率、资产逻辑关系识别覆盖率、智能找数检索准确率

智能任务执行趋势图（近7天调用量）

最近智能任务执行记录列表

大模型API调用状态与配额监控

Mock数据： 8项智能体指标数据 + 30+条执行记录

页面2：元数据智能补全
路径： /intelligence/metadata-ai
图标： MagicStick
核心功能：

三步流程设计（Step向导）：

Step1 - 补全前状态识别：自动识别元数据缺失状态，展示缺失的表中文名、表摘要、字段描述、维度指标类型等信息清单

Step2 - AI触发配置：AI模型调用、提示词配置、大模型API对接配置；基于历史元数据记录学习命名规范与业务语义

Step3 - 补全后结果确认：智能填充表中文信息、表摘要、字段描述等；自动识别字段的维度指标类型和代码描述；提供人工确认/编辑入口

补全结果一键回写元数据

补全历史记录查询与追溯

交互： 三步向导 + 人工确认面板 + 大模型配置表单

页面3：智能分类分级
路径： /intelligence/classify
图标： Collection
核心功能：

智能分类模型配置与管理：内置分类标准/词库，支持模型版本管理

批量处理任务：创建、执行与进度监控

分类分级结果可视化展示（列表+统计图表）

人工复核入口：待审核清单，支持通过/驳回

按资产名称、分级检索复核

分类分级结果自动回写资产属性（资产分级、资产标签）

Mock数据： 20+个分类模型配置，1000+条分类结果

页面4：知识库管理
路径： /intelligence/knowledge
图标： Notebook
核心功能：

知识库分类管理（数据安全知识库、数据质量知识库等）

向量化存储管理：支持文档、结构化数据、图片等信息转化为Markdown格式，存储到向量数据库

向量检索与大模型API调用配置（毫秒级检索响应）

RAG智能问答界面：基于用户提问生成智能问答结果，结果溯源展示

知识服务发布：知识检索能力可按需编目注册为数据服务，供业务系统调用

知识入库审核流程

Mock数据： 2个知识库（数据安全/数据质量），200+条知识条目

页面5：数据治理智能体
路径： /intelligence/agent
图标： Cpu
核心功能：

四类智能体独立面板（Tab切换）：

元数据管理智能体：自动接入数据源并识别抽取技术元数据；技术元数据自动补全；资产信息自动补全；资产分类分级；资产评估报告自动生成

数据质量管理智能体：自动化规则执行；实时规则监控与分析；质量专项方案制定、执行与报告；自动化报告生成

数据资源管理智能体：智能分析与归类数据资产；资产目录信息确认（可视化界面）；资产挂载目录信息回写（一键回写、批量操作）

智能找数智能体：问答式数据搜索（自然语言语义解析）；数据关系视图自动生成

智能体可视化配置调整（根据集团实例模式变化进行流程化调整）

智能体调用日志与执行记录查询

Mock数据： 4类智能体各50+条执行记录
