二、页面详细内容
页面1：数据源列表
路径： /datasource/list
图标： List
核心功能：

多类型数据源统一展示（结构化/半结构化/非结构化）

卡片/列表视图切换，支持按状态、类型、负责人筛选

连通性一键测试，连接状态实时展示（已连接/连接中/已断开/异常）

数据源基础信息维护（名称、描述、负责人等）

支持自定义数据源类型扩展

Mock数据： 50+个数据源实例

页面2：数据源注册
路径： /datasource/register
图标： Edit
核心功能：

分步引导接入向导（选择类型 → 配置参数 → 测试连接 → 完成）

支持数据源类型：MySQL、Oracle、SQLServer、MongoDB、HBase、OceanBase、GaussDB、虚谷、金仓、崖山、Kafka、RabbitMQ、JSON/XML/CSV、文本/图片/音视频等

连接参数配置，敏感信息（密码等）加密存储、界面掩码显示

自定义数据源适配：上传/更新JDBC驱动包

已使用数据源在采集任务中自动识别并防止重复接入

交互： 步骤条Step + 动态表单（根据数据源类型切换）

页面3：连接池管理
路径： /datasource/connection-pool
图标： SetUp
核心功能：

连接池参数配置：最大连接数、最小空闲连接数、连接超时时间

连接健康检查与自动回收（定期检测并清理无效连接）

连接池运行状态实时查看（活跃连接数、空闲连接数、等待线程数）

连接池配置变更留痕审计

页面4：参数模板管理
路径： /datasource/template
图标： Files
核心功能：

开发/测试/生产环境连接参数模板管理

模板快速复制与一键套用（快速创建新数据源）

模板版本管理，支持回滚

按模板类型、环境筛选

页面5：分组管理
路径： /datasource/group
图标： Folder
核心功能：

按业务域、数据类型、重要性等维度自定义分组

树形分组展示，支持拖拽移动数据源

分组下数据源数量统计

分组级权限控制（按组授权）

交互： 树形结构 + 拖拽

页面6：数据源监控
路径： /datasource/monitor
图标： Monitor
核心功能：

连接状态定时探测与告警（自动检测异常）

性能指标监控：响应时间、连接数、吞吐量

连接日志监控（异常连接追踪）

告警级别配置：提示/警告/严重，通知方式：站内/邮件/短信

告警历史查询与统计
