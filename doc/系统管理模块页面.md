   ├── 🔑 角色权限（二级菜单，图标：UserFilled）
   ├── 📊 运维监控（二级菜单，图标：Monitor）
   └── 📋 操作日志（二级菜单，图标：Document）
二、页面详细内容
页面1：用户管理
路径： /system/user
图标： User
核心功能：

用户CRUD（新增、编辑、删除、查询）

用户状态管理（启用/停用）

租户关联（分配用户至指定租户）

统一身份认证集成（SSO/LDAP账号对接）

用户密码策略（复杂度要求、定期修改）

登录记录查看（最近登录时间、IP）

支持批量导入/导出用户

Mock数据： 50+个用户

页面2：角色权限
路径： /system/role
图标： UserFilled
核心功能：

角色CRUD（新增、编辑、删除、查询）

权限分配：菜单权限（哪些菜单可见）、按钮权限（哪些操作可执行）、数据权限（可访问的数据范围）

角色绑定用户（为用户分配角色）

权限矩阵可视化展示

角色复用与克隆

权限变更审计（谁改了权限、何时改的）

Mock数据： 10+个角色（管理员、数据治理员、开发者、只读用户等）

页面3：运维监控
路径： /system/monitor
图标： Monitor
核心功能：

资源监控仪表盘：CPU使用率、内存使用率、存储空间、网络吞吐量（ECharts实时仪表盘）

治理任务运行状态全程监控（任务成功率、执行时长、异常任务数）

预警机制：自定义阈值告警（站内/邮件/短信）

系统容量评估：定期评估系统容量与运行性能，提供扩容与优化建议

容量趋势分析（近30天资源使用趋势）

治理任务高可用保障：任务失败自动重试配置

Mock数据： CPU/内存/存储实时指标 + 30天趋势数据

页面4：操作日志
路径： /system/log
图标： Document
核心功能：

操作审计日志查询（操作人、时间、操作类型、操作对象、结果、IP地址）

多条件筛选：时间范围、操作类型（登录/查询/修改/删除/审批）、操作人、租户

日志详情查看（请求参数、返回结果、耗时）

日志导出（Excel/CSV）

日志保存周期：系统日志、操作记录存放180个自然日

异常行为标记与告警

Mock数据： 500+条操作日志

三、菜单配置代码（一键复制）
typescript
// router/system.routes.ts
{
  path: '/system',
  name: 'System',
  meta: {
    title: '系统管理',
    icon: 'Setting',
    order: 10
  },
  redirect: '/system/user',
  children: [
    {
      path: 'user',
      name: 'UserManage',
      component: () => import('@/pages/system/user.vue'),
      meta: { title: '用户管理', icon: 'User' }
    },
    {
      path: 'role',
      name: 'RolePermission',
      component: () => import('@/pages/system/role.vue'),
      meta: { title: '角色权限', icon: 'UserFilled' }
    },
    {
      path: 'monitor',
      name: 'SystemMonitor',
      component: () => import('@/pages/system/monitor.vue'),
      meta: { title: '运维监控', icon: 'Monitor' }
    },
    {
      path: 'log',
      name: 'OperationLog',
      component: () => import('@/pages/system/log.vue'),
      meta: { title: '操作日志', icon: 'Document' }
    }
  ]
}
