二、页面详细内容
页面1：安全总览
路径： /security/overview
图标： DataAnalysis
核心功能：

安全态势总览：租户数、权限策略数、审计日志数、合规检查通过率

安全事件统计（按严重程度分布饼图）

合规状态仪表盘（各法规条款符合率）

近期安全告警列表（最新5条）

加密与脱敏覆盖统计（已加密表/字段占比）

Mock数据： 8个租户，50+权限策略，500+审计日志

页面2：多租户管理
路径： /security/tenant
图标： OfficeBuilding
核心功能：

租户CRUD（新增、编辑、删除、查询）

租户数据与资源隔离（存储、计算、调度独立）

租户账号对接（支持LDAP/SSO集成）

租户资源配额管理（存储空间、任务并发数限制）

租户状态管理（启用/停用）

Mock数据： 8个租户（设计单位、监理单位、施工单位等）

页面3：访问控制
路径： /security/access-control
图标： Key
核心功能：

基于角色（RBAC）与属性（ABAC）的权限管控

权限细化至表、字段、行级别（精细化授权）

数据权限申请 → 审批 → 授权 → 回收全流程管理

权限有效期管理（自动到期回收）

权限变更审计（谁、何时、改了什么）

权限矩阵可视化展示

交互： 权限矩阵表格 + 策略配置表单 + 审批流程

页面4：安全审计
路径： /security/audit
图标： Document
核心功能：

访问与治理操作日志全面记录（操作人、时间、对象、结果、IP）

日志查询与导出（多条件筛选：时间范围、操作类型、操作人）

操作溯源（点击日志可查看完整操作链）

异常行为检测与标记

审计日志保存180个自然日

合规举证材料一键导出

Mock数据： 500+条审计日志

页面5：加密与脱敏
路径： /security/encryption
图标： Shield
核心功能：

传输加密配置（HTTPS强制）

存储加密配置（算法选择、密钥管理）

密钥生命周期管理（创建、轮换、销毁）

动态脱敏（查询时实时脱敏）

静态脱敏（存储时脱敏）

脱敏规则配置：替换、掩码、哈希（保留格式）

脱敏规则版本管理与审批流程

Mock数据： 20+条脱敏规则

页面6：合规治理
路径： /security/compliance
图标： Checked
核心功能：

监管要求映射：《数据安全法》《个人信息保护法》等条款映射到系统功能

合规检查清单与自动检查

合规检查报告生成（含风险项列表）

风险提示与整改跟踪（风险→工单→整改→验证闭环）

合规审计证据归档

Mock数据： 50+条合规检查项
