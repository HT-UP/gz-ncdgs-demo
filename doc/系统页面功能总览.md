# 系统页面功能总览

> 本文档依据「广州地铁·新线建设数据治理系统」现有页面功能整理而成，按模块逐一说明每个页面的功能设计方案。
>
> 系统为 Vue 3 + TypeScript + Element Plus 单页应用，采用「左侧导航 + 顶层面包屑 + 内容区卡片」的布局，所有页面遵循统一的视觉风格（主色 #da251d，卡片化面板）。页面数据以 Mock 数据驱动，交互上支持表格分页、筛选、搜索、新增/编辑弹框、详情抽屉/弹框、步骤条流程引导、状态标签与图表化进度展示，布局全部采用响应式网格，避免横向滚动。

## 一、工作台与驾驶舱

### 1. 工作台（/dashboard）· Workbench.vue
- 登录后的默认落地页，聚合高频治理任务入口。
- 设计为「待办提醒 + 快捷入口 + 治理概览」组合：展示今日待办（标准的待审核、权限申请、质量问题工单等）、常用功能快捷卡片、系统运行概览与最近动态，帮助用户快速进入具体治理工作。

### 2. 数据治理驾驶舱（/cockpit）· dashboard/cockpit.vue
- 数据治理成果的总览大屏，以卡片、统计数字与趋势图展示全局治理指标（资产规模、标准覆盖率、质量通过率、安全合规率、智能体运行数等）。
- 采用「指标卡 + 图表区」布局，按数据源、分层、主题等维度提供下钻入口，面向管理层提供治理成效的全局视图。

## 二、数据标准管理

### 1. 标准列表（/standard/list）· standard/list.vue
- 分四类（业务术语 / 数据元 / 参考数据 / 指标标准）展示标准台账，支持类型 Tab 切换、名称/编码搜索、业务域/责任人/状态多条件筛选与分页。
- 新增/编辑弹框与列表字段完全对齐：标准编码（自动生成，只读）、标准名称、类型、业务域、责任人、版本、状态、更新时间、映射字段数、描述；编码冲突自动兜底。行点击打开详情（含映射字段、状态标签、描述）。

### 2. 模型影响分析（/standard/impact）· standard/impact.vue
- 面向标准/模型变更的影响评估：选择变更对象后自动计算下游影响对象（物理表、开发任务、数据服务、报表、标准映射）。
- 以「影响对象清单 + 链路图 + 风险评估」呈现，支持按影响层级过滤与一键导出影响报告。

### 3. 模型设计（/standard/model-design）· standard/model-design.vue
- 支持概念模型、逻辑模型、物理模型三层设计，提供字段管理、主键/约束配置与建模规范检查。
- 设计为「模型树 + 表结构编辑器 + 规范校验」结构，模型间可联动同步。

### 4. 数据质量标准（/standard/quality-standard）· standard/quality-standard.vue
- 定义数据质量标准体系：非空、格式、字典值域、唯一性、一致性、时效性等质量约束的标转化配置。
- 以「质量指标定义 + 标准阈值 + 适用范围」表格管理，与质量管理模块规则打通。

### 5. 标准实施监控（/standard/implementation）· standard/implementation.vue
- 跟踪标准的落地实施情况：统计标准引用率、字段贴合度、落标率并按业务域排名。
- 以「实施进度条 + 落标率趋势 + 未落标明细」呈现，支持下钻到具体资产与字段。

### 6. 标准版本管理（/standard/version）· standard/version.vue
- 管理标准的版本演进：版本列表、基线对比、变更记录与回滚操作。
- 采用「版本时间线 + 差异对比 + 发布记录」结构，支持版本间字段差异高亮展示。

### 7. 标准生命周期状态管理（/standard/lifecycle）· standard/lifecycle.vue
- 实现标准「草稿 → 待审核 → 已发布 → 已废止」状态机流转。
- 以状态机卡片 + 生命周期记录表格呈现，支持流转操作（提交审核、审核通过/驳回、发布、废止、恢复），每种状态配置对应操作按钮与权限提示。

### 8. 标准批量导入（/standard/batch-import）· standard/batch-import.vue
- 支持通过 Excel 模板批量导入四类标准，提供下载模板、文件上传、逐行校验、错误反馈与导入结果报告。
- 采用「导入向导步骤条 + 校验清单表格 + 结果统计」流程，展示成功/失败/跳过行及失败原因。

### 9. 标准批量废止（/standard/batch-retire）· standard/batch-retire.vue
- 实现「批量选择 → 引用检查 → 批量审批 → 废止执行」四步标准废止流程。
- 引用检查阶段展示待废止标准的引用对象（表/任务/服务）与风险提示；审批由流程步骤推动，废止执行后输出结果清单。

### 10. 数据元映射自动发现（/standard/mapping-find）· standard/mapping-find.vue
- 提供数据元与字段的自动映射推荐：按「名称 40% + 类型 20% + 值域 20% + 语义 20%」四维匹配计算推荐分值。
- 以「发现任务 + 推荐映射列表（置信度/得分）+ 人工确认/调整/忽略」设计，支持一键采纳批量建立映射。

### 11. 标准发布通知配置（/standard/publish-notify）· standard/publish-notify.vue
- 配置标准发布的通知范围（按角色 / 部门）并跟踪发布记录。
- 设计为「发布任务配置 + 通知对象选择 + 发布记录跟踪」结构，标准发布后自动向相关责任人发送站内信。

### 12. 落标率钻取分析（/standard/fallout-drill）· standard/fallout-drill.vue
- 支持落标率五层钻取：总览层 → 维度层 → 明细层 → 整改层 → 对比层。
- 以「落标率趋势图 + 维度分析表 + 逐层折叠下钻」呈现，可定位到具体未落标字段并查看整改建议与对比变化。

## 三、数据源管理

### 1. 数据源列表（/datasource/list）· datasource/list.vue
- 系统内数据源台账管理：展示数据源名称、类型、地址、连接状态、健康度、负责人等，支持搜索、状态筛选与操作入口（注册、测试、编辑、删除、监控）。

### 2. 数据源注册（/datasource/register）· datasource/register.vue
- 单数据源注册向导：填写基本信息、连接参数、归属分组与责任人，注册后可立即发起连通性测试。
- 采用表单分组（基本信息 / 连接配置 / 高级选项）的步骤式布局。

### 3. 连接池管理（/datasource/connection-pool）· datasource/connection-pool.vue
- 管理各数据源的连接池：池大小、最大连接数、空闲超时、获取等待时间、借出连接等参数配置；展示运行状态监控与连接池泄漏防护指标（泄漏计数、拦截记录）。

### 4. 参数模板管理（/datasource/template）· datasource/template.vue
- 提供连接参数模板的创建、编辑、分类与复用，同一类型数据源可套用统一模板降低配置成本。

### 5. 分组管理（/datasource/group）· datasource/group.vue
- 按业务分组（运营库组 / 采集库组 / 分析库组等）组织数据源，支持分组内数据源拖拽调整、批量分配与数量统计。

### 6. 数据源监控（/datasource/monitor）· datasource/monitor.vue
- 数据源运行状态实时监控：在线状态、健康度、连接数、操作量、告警信息的统一监控视图，支持告警确认与处置。

### 7. 数据源健康度评估（/datasource/health）· datasource/health.vue
- 按「连通性 30% + 稳定性 30% + 性能 25% + 容量 15%」四维加权计算综合健康度，输出「健康 / 关注 / 异常」三档分级。
- 页面包含综合健康度仪表盘、各维度得分进度条、健康分布柱图与数据源健康度清单表，清单内展示各维得分与等级标签。

### 8. 数据源日志分析（/datasource/log-analysis）· datasource/log-analysis.vue
- 围绕数据源日志提供五维分析：操作画像（操作类型分布、活跃用户）、失败分析（失败类型、原因明细）、性能分析（响应时间、慢查询 TOP）、趋势分析（访问/失败 7 日趋势）、安全分析（越权、异常登录、审计合规）。
- 采用 Tab 页签切换五个分析维度，各维度独立呈现图表与表格。

### 9. 数据源连通性测试（/datasource/connectivity-test）· datasource/connectivity-test.vue
- 按「网络层 → 认证层 → 连接层 → 权限层 → 数据层」五层顺序执行连通性校验。
- 以步骤卡片展示每层测试状态（待测/测试中/通过）与耗时，全部通过后给出测试结果汇总并支持保存测试记录。

### 10. 驱动管理（/datasource/driver）· datasource/driver.vue
- 管理数据库连接驱动：驱动上传（jar）、类型注册、版本管理、安全校验（签名状态）、使用跟踪（关联数据源与使用次数）。
- 提供上传弹框（选择驱动文件、数据库类型、版本号）与统计卡片（驱动总数/已签名/待升级/本月上传）。

### 11. 数据源批量注册（/datasource/batch-register）· datasource/batch-register.vue
- 支持 Excel 批量导入数据源，流程为「导入 Excel → 批量校验 → 批量分组 → 注册报告」。
- 校验阶段逐行给出通过/需确认/失败原因；分组阶段批量分配业务分组；报告阶段汇总成功/失败数量并列出失败原因与处理建议。

### 12. 数据源性能监控（/datasource/perf-monitor）· datasource/perf-monitor.vue
- 面向数仓数据库与大数据平台的性能监控：平均查询响应、写入吞吐、CPU/内存利用率指标卡与近 1 小时指标曲线。
- 下方展示采集任务性能明细（状态、处理记录、吞吐、平均耗时、资源占用进度），异常任务以红色标记。

## 四、元数据管理

### 1. 元数据总览（/metadata/overview）· metadata/overview.vue
- 元数据规模与运营总览：元模型数、数据元数、采集任务数、标签覆盖等统计卡，配合采集趋势与标签分布图。

### 2. 元模型管理（/metadata/model）· metadata/model.vue
- 管理元数据模型（实体、属性、关系），提供元模型的新增、编辑、版本与关系维护，是元数据体系的骨架。

### 3. 数据元管理（/metadata/data-element）· metadata/data-element.vue
- 数据元编目管理：展示数据元标识、名称、类型、长度、值域、来源标准等，支持按标准检索与详情查看。

### 4. 元数据采集（/metadata/collection）· metadata/collection.vue
- 元数据采集任务管理：采集任务创建、源表范围、采集周期与采集状态，支持手动触发与结果查看。

### 5. 采集调度中心（/metadata/schedule）· metadata/schedule.vue
- 管理元数据采集的调度计划（定时/增量/事件触发），以日历式或列表式呈现调度排期与执行记录。

### 6. 血缘解析（/metadata/lineage）· metadata/lineage.vue
- 表级/字段级血缘图谱：展示来源表 → 加工 → 目标表链路，支持按表检索血缘并查看解析任务。

### 7. 数据标签管理（/metadata/tag）· metadata/tag.vue
- 标签体系维护：标签分类、标签创建/启用停用、标签打标规则与打标记录，支持给资产批量打标签。

### 8. 元数据采集概览（/metadata/collection-overview）· metadata/collection-overview.vue
- 采集运行状态看板：数据源类型覆盖、采集完成率、成功率、待处理任务统计，配合各数据源采集维度明细与最近采集动态。

### 9. 元数据采集失败处理（/metadata/collection-failure）· metadata/collection-failure.vue
- 按「连接失败 / 权限失败 / 解析失败 / 超时失败 / 变更冲突」分类统计并集中处理采集失败任务。
- 支持失败原因查看、单条重试、忽略，以及多选批量重试；每条任务可开关自动重试。

### 10. 数据标签统计（/metadata/tag-stats）· metadata/tag-stats.vue
- 五维标签统计：使用频率 TOP、分布情况（按标签类别）、覆盖情况（按业务域覆盖率）、使用趋势（近期打标量）、关联特征（协同出现标签推荐）。

### 11. 数据标签规则冲突处理（/metadata/tag-conflict）· metadata/tag-conflict.vue
- 处理打标规则冲突：多规则命中、互斥标签、规则与人工冲突、标签层级冲突四类。
- 以分类统计卡 + 冲突清单呈现，每条给出冲突详情、处理建议与处理状态，支持批量处理。

### 12. 元数据版本管理（/metadata/version）· metadata/version.vue
- 元数据变更版本管理：变更申请 → 影响评估 → 审批 → 实施 → 发布通知五步流程驱动。
- 展示版本变更记录、影响评估信息（下游任务/服务/订阅者）与审批进展时间线。

### 13. 元数据版本通知（/metadata/version-notify）· metadata/version-notify.vue
- 版本发布后自动通知四类对象：表/字段责任人、下游任务责任人、服务调用方、订阅用户。
- 页面展示通知列表（范围、状态、发送时间）与通知对象统计卡。

### 14. 元数据检索增强（/metadata/search）· metadata/search.vue
- 提供全文检索、组合检索、语义检索三种模式，命中结果标注相似度。
- 检索前展示热门检索词与能力介绍卡片；检索后展示结果列表（类型、名称、描述、标签、相似度），并支持相似推荐。

## 五、数据开发集成

### 1. 开发总览（/datadev/overview）· datadev/overview.vue
- 开发集成工作台总览：任务规模、运行状态、近期开发动态、资源使用概览，快速进入批/流/实时开发。

### 2. 批量处理（/datadev/batch）· datadev/batch.vue
- 批量 ETL 任务开发与管理：批任务列表、开发编排、依赖关系、执行批次与结果查看。

### 3. 实时处理（/datadev/realtime）· datadev/realtime.vue
- 实时处理任务开发与管理：实时任务状态、数据接入速率、延迟与积压监控。

### 4. 流式数据处理（/datadev/stream）· datadev/stream.vue
- 流式任务管理：流任务列表、Kafka 主题接入、窗口配置与计算状态。

### 5. 任务管理（/datadev/task）· datadev/task.vue
- 开发任务统一台账：任务生命周期（草稿 → 待审核 → 发布 → 运行中 → 暂停 → 终止 → 归档）状态展示，支持任务发布、暂停、终止等操作。

### 6. 采集任务配置（/datadev/collect-config）· datadev/collect-config.vue
- 数据采集任务配置：源/目标选择、采集方式（全量/增量）、调度频率、字段映射与运行配置。

### 7. 任务监控（/datadev/monitor）· datadev/monitor.vue
- 开发任务运行监控：运行状态、耗时、成功率、积压量监控，异常任务告警与重跑入口。

### 8. 流程化配置（/datadev/flow）· datadev/flow.vue
- 可视化流程编排：节点式 ETL 流程设计、节点参数配置、流程保存/发布与运行控制。

### 9. 安全与合规（/datadev/security）· datadev/security.vue
- 开发链路安全合规：任务权限、脚本安全扫描、敏感操作审计与合规检查项。

### 10. 任务调度与执行架构（/datadev/schedule-arch）· datadev/schedule-arch.vue
- 展示「调度中心 + 执行节点」的分层调度架构：调度中心负责策略编排、失败重试、并发控制、优先级与补偿机制。
- 页面含架构可视化图（调度中心 → 分发 → 执行节点）、调度策略配置表、节点负载进度条与调度任务执行记录表（含重试次数与补偿状态）。

### 11. 刷新采集与数据比对（/datadev/refresh-compare）· datadev/refresh-compare.vue
- 对源表与目标表进行刷新比对，自动识别「新增 / 更新 / 删除」三类差异。
- 以「比对任务 + 差异明细」两个页签组织：任务页展示各比对任务的差异统计标签；明细页逐条列出差异类型、主键、源/目标值与差异字段，支持单条同步。

### 12. 实时窗口计算（/datadev/window-calc）· datadev/window-calc.vue
- 提供滑动窗口、滚动窗口、会话窗口三类窗口计算能力说明与任务管理。
- 页面展示窗口类型卡片（窗口定义、典型场景）与窗口计算任务表（窗口类型、大小、触发频率、计算结果、运行状态）。

### 13. 流式数据处理增强（/datadev/stream-adv）· datadev/stream-adv.vue
- 集成 Flink / Spark Streaming / 流批一体协同三种引擎，支持 CEP 复杂事件处理。
- 页面含引擎切换、引擎集成状态、CEP 规则列表（模式、触发记录）与流批一体作业表。

### 14. AI 智能化开发集成（/datadev/ai-dev）· datadev/ai-dev.vue
- 提供自然语言生成 SQL / 转换规则、智能推荐算子、异常智能诊断能力。
- 布局为「NL 生成区 + 智能推荐区」：左侧输入自然语言生成 SQL（带置信度、可执行），右侧展示推荐算子与异常诊断卡片。

### 15. 流程断点调试（/datadev/breakpoint）· datadev/breakpoint.vue
- 流程可视化断点调试：断点设置 → 暂停查看 → 断点续跑。
- 以节点流展示各节点状态（含断点标记），暂停时高亮命中节点并展示断点列表与中间数据预览，支持继续运行/结束调试。

### 16. 单步执行与数据预览（/datadev/step-preview）· datadev/step-preview.vue
- 支持流程逐节点单步执行、分支验证（主分支/异常分支/补数分支）与数据预览。
- 数据预览受权限约束：L3 及以上敏感字段脱敏展示、预览行数上限、全量数据需探查权限，并以统计卡说明可预览/脱敏/受控字段数。
